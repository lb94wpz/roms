### FC

全称：Family Computer（日本）/ Nintendo Entertainment System（NES，欧美）

历史：

- 1983年7月15日由任天堂在日本推出，1985年以NES名义登陆北美，重塑因“雅达利崩溃”濒临消亡的游戏市场。

- 采用8位处理器，支持56色显示，首创“第一方+第三方”游戏合作模式，吸引Square、Konami等厂商。

- 北美初期销售遇冷，后凭《超级马力欧兄弟》逆袭，占据美国90%市场份额。

经典游戏：《超级马力欧兄弟》《塞尔达传说》《魂斗罗》《勇者斗恶龙》。

销量：全球6191万台（1983-2004年）。

### SFC

全称：Super Family Computer（日本）/ Super Nintendo Entertainment System（SNES，欧美）

历史：

- 1990年发布，任天堂首款16位主机，对抗世嘉MD。采用定制硬件（音频芯片由索尼开发），首次搭载肩键手柄。

- 原生支持RGB输出，画面表现优于同期主机。因硬件加密技术，山寨难度极高。

- 非官方磁碟机配件流行，降低正版游戏成本。

经典游戏：《超级马力欧世界》《塞尔达传说：众神的三角力量》《最终幻想6》《火焰之纹章：圣战系谱》。

销量：全球4910万台，任天堂最成功的16位主机。

### N64

全称：Nintendo 64（因64位处理器命名）

历史：

- 1996年推出，任天堂首款支持3D图形的主机。坚持使用卡带（非光盘），导致第三方流失。

- 首创类比摇杆、扳机按键和震动包，奠定现代手柄标准。

- 北美首发两周销量破百万，但因卡带成本高、容量小，最终败于索尼PS1。

经典游戏：《超级马力欧64》《塞尔达传说：时之笛》《007黄金眼》。

销量：全球3293万台。

### GB

全称：Game Boy

历史：

- 1989年发布，全球首款成功便携式游戏机。黑白屏幕、低功耗设计（4节AA电池续航30小时）。

- 凭借《俄罗斯方块》捆绑策略打开市场，后期《精灵宝可梦 红/绿》引发现象级热潮。

- 击败同期世嘉Game Gear等高性能但高耗电竞品。

经典游戏：《俄罗斯方块》《精灵宝可梦 红/绿》《星之卡比》。

销量：全球超1.18亿台，开创掌机市场。

### GBC

全称：Game Boy Color

历史：

- 1998年发布，GB的升级版，支持最大56色显示。确立“向下兼容”为掌机核心特性。

- 专为GBC开发的游戏可发挥彩色优势，旧GB游戏仅显示4-10色。

- 因TV动画《精灵宝可梦》“3D龙事件”影响，发售从1998年1月推迟至10月。

经典游戏：《塞尔达传说：梦见岛DX》《宝可梦 金/银》《瓦力欧大陆3》。

销量：约1.18亿台（与GB合并统计）。

### GBA

全称：Game Boy Advance

历史：

- 2001年推出，32位掌机，兼容GB/GBC游戏。采用TFT彩色屏幕，性能大幅提升。

- 2003年推出翻盖改款GBA SP，加入背光功能；2005年推出微型版GBM。

- 国内由神游代理（小神游GBA），因不锁区且支持盗版卡带热销。

经典游戏：《黄金太阳》《火焰之纹章》《宝可梦 红宝石/蓝宝石》《逆转裁判》。

销量：全球8151万台。

### NDS

全称：Nintendo Dual Screen（因双屏设计命名）

历史：

- 2004年12月2日在日本首发，创新性采用触控双屏设计，下方屏幕支持触控笔操作。

- 凭借价格优势及《任天狗》《脑锻炼》等大众化软件，击败索尼PSP，扩展非传统玩家群体。

- 后续推出DS Lite、DSi等改款，神游代理版在国内发售。

经典游戏：《新超级马力欧兄弟》（3080万套）、《精灵宝可梦 钻石/珍珠》《动物森友会》。

销量：全球1.54亿台（含衍生型号），史上第二畅销游戏主机。

### MD

全称：Mega Drive（日本）/ Genesis（北美）

历史：

- 世嘉1988年推出的16位主机，以“Genesis”名义登陆北美，主打高性能（7.67MHz CPU）。

- 凭借《索尼克》系列（速度感设计对抗马力欧）与任天堂SFC激烈竞争。

- 北美营销强调“不是孩子玩具”，吸引青少年用户。

经典游戏：《索尼克》《怒之铁拳》《梦幻模拟战》《幽游白书 魔强统一战》。

销量：全球3075万台，世嘉最成功主机。

### NGPC

全称：Neo Geo Pocket Color（彩色版）/ Neo Geo Pocket（NGP，黑白初版）

历史：

- 1998年10月28日，SNK在日本推出黑白屏掌机Neo Geo Pocket（NGP），主打格斗游戏和摇杆操作优化。

- 因任天堂GBC彩色掌机同期发布，SNK于1999年3月紧急推出彩屏版NGPC，但因背刺早期用户引发争议。

- 性能强于GBC（同显146色），但游戏阵容单一（超70%为格斗移植作），缺乏RPG等大众品类。

经典游戏：《拳皇R-1/R-2》《侍魂》《索尼克口袋大冒险》《SNK VS CAPCOM卡片战士》。

销量：全球仅200万台，因SNK 2000年破产重组而退市。
